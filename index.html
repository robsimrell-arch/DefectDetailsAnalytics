How to Export Defect Details from TIME² System
Step 1: Navigate to Report
In TIME², go to PFSv4 Reports ➔ PFSv4 PO/Date Info ➔ Defect Details.
Step 2: Build & Execute Query
Select all programs (using Shift+Click), select date range, check Exclude NDFs, click Execute, and download the Excel/CSV file (located at the bottom of the report).
